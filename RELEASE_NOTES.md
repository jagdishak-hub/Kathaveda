# The Reading Room update

Renamed the app, added a colourful animated Home page and book-and-lamp logo, and introduced clear navigation into reading, learning, situations, games and conversation.

Expanded the source database to 31 collections and 9,942 units. The new Shiva Purana source contains 457 Sanskrit chapters across all seven samhitas of the named Wikisource edition. English chapters open inside the tool. The Gita’s paired Sanskrit/English 1922 edition preserves its 701-verse numbering. New archives are split into integrity-checked parts for reproducible deployment.

Added self-recording and scheduled verse review. Pronunciation audio coverage remains incomplete; no full teacher-verified course is claimed. Complete Purana coverage, specialist-reviewed simple meanings and broader question coverage within every game stage remain unfinished. Live provider answers still require a configured working key.

The interface now uses a calm garden palette with an optional browser-generated flute-and-bird soundscape. The sidebar remains a grouped navigation panel with an active-page marker, profile status and reviews due. The Situations section contains 60 practical cards. Games add trail visuals, selectable round lengths, streaks, lotus points and badges across 25 scripture-focused stages. Converse defaults to OpenRouter, retains direct-provider fallback, and reports model/key/quota problems more clearly.
